# 🧠 Portal BZ: База Знаний (Telegram Bot & Mini App)

Интерактивная База Знаний и навигационный каталог (392 отборных материала), созданный на основе сохраненных постов и Reels из Instagram. Полностью очищен от рекламы, маркетингового мусора и кликбейта.

---

## 🌟 Возможности проекта

### 1. 🧼 Чистые и структурированные карточки
* Полное отсутствие клише («пиши в директ», «скину в лс», «подпишись»);
* Каждая карточка содержит:
  * 📌 **Заголовок**
  * 👤 **Автор & Дата оригинала**
  * 🏷 **Каскадный путь (Хаб ➔ Раздел ➔ Подраздел)**
  * 📁 **Исходная папка Instagram** (сохранение контекста)
  * 💡 **В чём суть** (концентрированная польза и механика)
  * 📋 **Пошаговый разбор** (конкретные шаги, команды, инструменты)
  * 🎯 **Главный инсайт**
  * 🔗 **Прямая ссылка на оригинал в Instagram**

### 2. 🌳 Логическая функциональная иерархия (4 Хаба, 16 Разделов, 39 Подразделов)
* **🤖 AI & Нейросети (180 материалов)**
  * Вайб-кодинг & Разработка (Cursor, Claude Code, Скиллы, MCP)
  * Языковые модели & Промпты (CLAUDE.md, ChatGPT, DeepSeek)
  * Автоматизация & AI-Агенты (n8n, автономные агенты)
  * Креативный AI & Медиа (видео, голос, изображения)
  * Прикладные AI-инструменты (документы, генераторы сайтов)
* **📈 Маркетинг & E-com (96 материалов)**
  * Контент & Reels (алгоритмы, сценарии, удержание)
  * Маркетплейсы (WB / Ozon, оцифровка, СПП)
  * B2B-Продажи & Лидогенерация
  * Трафик & Платная реклама
* **🛠 Бизнес & Управление (104 материала)**
  * Бизнес-модели & Схемы заработка
  * Финансы & Управленческий учет (P&L, CashFlow, налоги)
  * Менеджмент & Процессы
  * Товарный бизнес, ВЭД & Производство (1688, фабрики)
  * **🧰 Инструменты, Сервисы & Подрядчики:**
    * 💳 *Платежки, Крипта & Зарубежные карты* (Whitebird СБП, зарубежные карты, P2P)
    * ⚙️ *Сервисы, Связь & VPN* (виртуальные SIM, выделенный VPN, кассовый контроль)
    * 📦 *Логистика, Карго & Авто* (карго из Китая, параллельный импорт авто, пошив в Турции)
    * 🤝 *Услуги, Продвижение & Подрядчики* (агентства трафика, видеопродакшн, клуб «Нечто»)
* **📌 Полезный софт & IT (12 материалов)**
  * IT, Безопасность & Утилиты
  * Дизайн, UI/UX & Web (Figma, лендинги)

## 📱 Telegram Mini App (TMA)
Автономное SPA-веб-приложение для Telegram:
* Адаптивная темная тема под дизайн Telegram;
* Мгновенный локальный поиск без перезагрузок;
* 3-уровневые каскадные фильтры (Хаб ➔ Раздел ➔ Подраздел);
* Избранное / закладки (сохраняются локально в браузере);
* Тактильная отдача (Haptic Feedback) Telegram WebApp.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
python3 -m pip install -r requirements.txt
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе примера:
```bash
cp .env.example .env
```
Укажите ваш `BOT_TOKEN` и `WEBAPP_URL`.

### 3. Запуск бота
```bash
python3 bot.py
```

### 4. Запуск в Docker
```bash
docker build -t portal-bz-bot .
docker run -d --env-file .env portal-bz-bot
```
