# 🧠 База Знаний: Telegram-Бот & Telegram Mini App (TMA)

Интерактивная база знаний, сформированная из сохраненных видео и постов Instagram (1 136 материалов), полностью очищенная от маркетингового шума («сохрани», «пиши в директ») и подготовленная для масштабирования в веб- и мобильное приложение.

---

## 🚀 Новые возможности

### 1. 🧼 Полная очистка от шума и клише
* Удалены призывы к действию («пиши в директ», «скину в лс», «сохрани чтобы не потерять»);
* Удалены юридические дисклеймеры и реклама сторонних курсов;
* Каждая карточка содержит только концентрированную пользу:
  * 📌 **Заголовок**
  * 💡 **В чём суть** (проблема и решение)
  * 📋 **Пошаговый разбор** (команды, шаги, алгоритмы)
  * 🛠 **Инструменты**
  * 🎯 **Главный практический инсайт**

### 2. 🧭 Глубокая и удобная навигация в Telegram
* **Каталог со списком карточек (по 5 на странице):**
  * Больше не нужно листать по 200 постов по одному!
  * Отображается список с названиями и кнопками `[ 1️⃣ ] [ 2️⃣ ] [ 3️⃣ ] [ 4️⃣ ] [ 5️⃣ ]`;
  * Удобный переход по страницам `[ ⬅️ Стр ] [ 1/18 ] [ Стр ➡️ ]`;
  * Кнопка `[ 🔙 К списку ]` в карточке возвращает ровно на ту страницу каталога, где вы были.

### 3. 📱 Готовая архитектура Telegram Mini App (TMA)
* **Папка `web_app/index.html`:** полноценное современное SPA-приложение для Telegram:
  * Адаптивный интерфейс под темную тему Telegram;
  * Живой мгновенный поиск без перезагрузок;
  * Фильтрация по разделам и тегам (`#mcp`, `#claude-code`, `#n8n`, `#video-ai`, `#prompts`, `#reels-growth`);
  * Аккордеон с пошаговыми инструкциями;
  * Избранное (сохраняется локально и в базе);
  * Нативная тактильная отдача (Haptic Feedback).
* **Встроенный сервер `server.py`:**
  * Работает на чистом Python 3 без сторонних зависимостей;
  * Предоставляет REST API (`/api/posts`, `/api/categories`, `/api/tags`, `/api/posts/{id}`);
  * Раздает Mini App на `http://localhost:8080`.

## 🛠 Запуск

### Запуск Telegram-бота:
```bash
BOT_TOKEN="ВАШ_ТОКЕН" python3 bot.py
```
*(Или `./run_bot.sh`, если токен в `.env`)*

### Запуск Telegram Mini App сервера:
```bash
python3 server.py
```
Сервер запустится на `http://localhost:8080`. Для подключения к Telegram Mini App достаточно пробросить адрес через Cloudflare Tunnel или ngrok (`ngrok http 8080`), либо развернуть `web_app` на Vercel / GitHub Pages.

## 📁 Структура проекта

* `knowledge_base.db` — SQLite база данных с семантическими тегами, подкатегориями и индексом FTS5;
* `bot.py` — бот на `aiogram 3` с глубокой навигацией списком и поддержкой Mini App;
* `db_helper.py` — слой доступа к данным с поддержкой постраничного каталога;
* `clean_and_enrich_v2.py` — конвейер глубокой очистки от спама и разметки тегов;
* `server.py` — легковесный REST API и статический сервер для Mini App;
* `web_app/index.html` — фронтенд Telegram Mini App (Tailwind CSS, JS);
* `run_bot.sh` — скрипт быстрого запуска.
